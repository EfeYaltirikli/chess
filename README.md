# zeichess

Ortak bir `.db` dosyası üzerinden (ağ klasörü) birden fazla bilgisayardan oynanan, Lichess benzeri satranç uygulaması (PySide6).

**İndir:** yeşil **Code** düğmesi → **Download ZIP**. Kurulum ve kullanım: `OKU.txt`.

```
py -m pip install PySide6 pyinstaller
py zeichess.py
py -m PyInstaller --noconfirm --onefile --windowed --name zeichess zeichess.py
```

Taş görselleri: Lichess "cburnett" seti (Colin M.L. Burnett, GPLv2+).
